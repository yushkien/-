# 연애 시뮬레이션 게임 (가제)

한국 고등학교 3학년을 배경으로, **인물 간의 관계(질투 / 견제 / 연합 / 하렘)**를
중심으로 한 미연시 프로젝트입니다.

- 배경: 고3 1년 (크리스마스 고백 → 졸업식 에필로그)
- 히로인 4명: 츤데레 / 메가데레 / 소프트 얀데레 / 소심한 쿨데레
- 핵심 설계: 루트를 미리 그리지 않고 **상태(수치)를 평가해 이벤트·엔딩을 계산**
- 엔진: **Ren'Py** (8.x / Python 3 기반)

## 저장소 구성

| 경로 | 설명 |
|------|------|
| `연애시뮬_설계문서.txt` | 전체 게임 설계 문서 (데이터 모델 · 질투 시스템 · 타임라인 · 엔딩) |
| `프로젝트_공유_개요.md` | 협업자 공유용 요약 (확정 사항 / 미정 사항) |
| `캐릭터_유형_자료집.md` | 성격/배경 2축 캐릭터 자료집 |
| `game/` | Ren'Py 프로젝트 (스크립트 · 로직) |

자세한 설계는 [`연애시뮬_설계문서.txt`](./연애시뮬_설계문서.txt) 참고.

## 프로토타입 실행 방법

1. [Ren'Py SDK](https://www.renpy.org/latest.html) 8.x 설치
2. Ren'Py 런처에서 `projects` 폴더를 이 저장소 루트로 지정
3. 목록에서 프로젝트를 선택해 **Launch Project**
   (또는 SDK의 `renpy.sh <저장소경로>` 로 직접 실행)
