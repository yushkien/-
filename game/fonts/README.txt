폰트 안내
=========

SourceHanSansLite.ttf
- 본고딕(Source Han Sans) Lite 버전. 한글/한자/일어 표시용.
- Ren'Py SDK에 동봉되어 배포되는 폰트로, SIL Open Font License 기반입니다.
- 현재는 한글 표시를 위한 "플레이스홀더" 용도로 사용 중입니다.
  최종 빌드 시 원하는 한글 폰트로 교체할 수 있습니다.
  (교체 시 game/gui.rpy 의 gui.text_font / name_text_font /
   interface_text_font 경로를 수정)
