# 프로토타입 (game/) 설명

관계·질투 시스템이 실제로 도는지 검증하기 위한 **최소 Ren'Py 프로토타입**.
아트 없음(텍스트만). 로직 검증용 수직 슬라이스.

## 파일 구성

| 파일 | 역할 |
|------|------|
| `data.rpy` | 히로인 4명 + 초기 관계값(쌍 6개) + 글로벌 상태 |
| `logic.rpy` | 핵심 로직: 질투 계산 · 연합/견제 판정 · 엔딩 평가 |
| `script.rpy` | 메인 흐름: 슬롯마다 행동 선택 → 상태 표시 → 엔딩 |
| `options.rpy` | Ren'Py 프로젝트 설정 (한글 폰트 설정 주석 포함) |

## 실행

Ren'Py 8.x SDK 설치 후, 런처에서 이 저장소 루트를 프로젝트로 지정해 Launch.

> ⚠️ 한글 표시: Ren'Py 기본 폰트는 한글을 못 그립니다.
> `game/fonts/`에 한글 폰트(.ttf, 예: Noto Sans KR)를 넣고
> `options.rpy`의 `gui.text_font` 주석을 해제하세요.

## 구현된 시스템 (설계 문서 대응)

- **질투**: 특정 히로인 편애 → 호감↑ + 타 히로인 질투↑ + 긴장 전이 (설계 4장)
- **방향성 긴장**: `tension_AtoB` 비대칭 (A→B와 B→A 별도) (설계 2-2)
- **견제**: bond 높은데(≥40) 긴장 높은(≥60) 쌍에서 발동 (설계 4-5)
- **연합**: 독주자 겨냥 긴장 높은 히로인 2+ → 임시 공조 (설계 4-5)
- **하렘 수용도**: 공평 행동으로 상승, 긴장을 유대로 전환 (설계 6장)
- **엔딩**: 최종 상태 평가로 하렘/굿/배드/노멀 자동 분기 (설계 7장)

## 검증 결과 (Python 로직 테스트)

로직을 순수 Python으로 추출해 4개 엔딩 경로를 검증 완료:

1. **편애 플레이**: 7회차 견제 발생 → 10회차 "원래 안 친한 A·C가 독주자 B를
   막으려 연합" 발생 → good 엔딩. (설계 의도대로 동작)
2. **하렘 지향 플레이**: 데이트/공평을 번갈아 질투·긴장을 0으로 관리하며
   전원 호감 60+ 달성 → 하렘 엔딩. (약 28슬롯의 꾸준한 관리 필요
   = "가장 어려운 엔딩"이 수치로 입증됨)
3. **질투 폭주**: 특정 히로인 질투 85+ → 배드 엔딩.
4. **무행동**: 노멀 엔딩.

### 튜닝된 밸런스 상수 (초기값, 추후 조정 가능)

- 데이트 시 긴장 전이 배율: `jealous × 1.6` (연합 임계 도달 핵심)
- 슬롯 종료 긴장 자연감소: `-2` (완만 — 편애 지속 시 축적되도록)
- 공평 행동: 질투 `-12`, 전원 호감 `+2`, 수용도 `+6`, 긴장→유대 전환
- 연합 임계: `tension_XtoL >= 60`, 독주자 격차 `> 25`
- 견제 임계: `bond >= 40` AND `tension >= 60`
